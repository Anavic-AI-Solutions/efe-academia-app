# Boletín de notas de padres (etapa 3) — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** El padre (y alumno/profesor/staff) ve el boletín completo de un alumno por aula en la app — notas por período con promedio de paridad-PDF, asistencia por período, inasistencias y observaciones públicas — y descarga el PDF oficial por URL firmada; la acción “Boletín” del home abre esta pantalla; la API queda autorizada.

**Architecture:** Backend: misma ruta del boletín con negociación `wantsJson()` (JSON para la app, PDF como hoy), `authorizeBoletin`, filtro de observaciones por rol, rutas `…/link` (auth+policy) y `…/file` (pública+signed), y unificación de reglas (promedios/justificadas) compartidas entre JSON y blade. Flutter: dominio `BoletinData`, api/repo/provider, `StudentBoletinScreen` (`/students/:id/boletin`) y actualización del home.

**Tech Stack:** Flutter 3.x + Riverpod 2 + go_router 14.8.1 + freezed (build_runner) + url_launcher 6; Laravel 11 (`efe-app`, contenedor `dev-efe`).

**Spec:** `docs/superpowers/specs/2026-10-16-boletin-design.md`

## Global Constraints

- **Paridad con el PDF**: `averages` = media simple de scores numéricos por período (redondeo 2, `null` sin datos); la clasificación justificada/sin justificar es la misma en JSON y en el PDF (helper único); la asistencia por período sale del `AttendanceCalculationService`.
- **Observaciones**: padre/alumno → solo `is_public = true`; admin/sucursal/profesor → todas; la ruta `file` (sin user) → solo públicas.
- **Policy** `authorizeBoletin`: admin/branch todo; padre → `student->parents()` con `parent_data.user_id`; alumno → propio; profesor → aula suya (`professor_data.user_id`); resto 403. Aplica a JSON, PDF y link.
- **Web intacto**: usa rutas propias (verificado); la ruta API no tiene consumidores.
- **efe-app: NO ejecutar Pest / `php artisan test`** (AGENTS.md). Verificación: `php -l`, `./vendor/bin/pint`, tinker en `dev-efe`.
- Montos/porcentajes con `AppFormatters` donde aplique; tests comparan contra el formatter (precedente R9 etapa 1).
- Textos ES+EN en ARB + `flutter gen-l10n`; sin strings hardcodeados.
- Claro y oscuro; contraste ≥4.5:1; `primarySoft` solo relleno decorativo.
- Gate de analyze: **sin issues nuevos** (baseline: 45 issues `info`/`warning`, 0 `error`).
- Commits por tarea (mensajes `feat:`/`fix:` en español, estilo del repo).

## Review Focus

1. Hijo sin aulas ⇒ `EmptyState` (no crash ni chips vacíos). (Task 5)
2. Aula sin notas pero con inasistencias ⇒ secciones parciales (Notas con `boletinNoGrades`, el resto visible). (Task 5)
3. `justified` con valores raros (`'no'`, `'false'`, `'0'`, `''`, null) ⇒ clasificación correcta en JSON y blade. (Task 1)
4. Fallo del link del PDF (404/red) ⇒ snackbar `boletinDownloadError`, sin crash. (Task 5)
5. Cambio de aula en los chips ⇒ refetch del boletín de esa aula (sin mezclar datos). (Task 5)
6. Promedio sin notas numéricas ⇒ `null` ⇒ badge oculto o “—” (nunca 0). (Tasks 1 y 5)

```php
private function boletinAverages($qualifications): array
{
    $averages = [];
    foreach ($qualifications->pluck('period')->unique() as $period) {
        $scores = $qualifications->where('period', $period)
            ->pluck('score')->filter(fn ($s) => is_numeric($s));
        $averages[(string) $period] = $scores->isNotEmpty()
            ? round((float) $scores->avg(), 2)
            : null;
    }
    return $averages;
}

private function absenceIsJustified(\App\Models\Absences $absence): bool
{
    return match (strtolower((string) $absence->status)) {
        'justified' => true,
        'pending', 'unjustified' => false,
        default => ($v = strtolower(trim((string) $absence->justified))) !== ''
            && ! in_array($v, ['no', 'false', '0'], true),
    };
}

private function absencesSummary($absences): array
{
    $justified = $absences->filter(fn ($a) => $this->absenceIsJustified($a))->sum('quantity');
    $total = (int) $absences->sum('quantity');
    return ['total' => $total, 'justified' => (int) $justified, 'unjustified' => $total - (int) $justified];
}
```

```php
public function boletinLink(Request $request, string $studentId, string $classroomId): JsonResponse
{
    $student = \App\Models\StudentData::findOrFail($studentId);
    $classroom = \App\Models\Classrooms::withoutGlobalScope('isNotArchivated')->find($classroomId);
    $this->authorizeBoletin($request->user(), $student, $classroom);

    return $this->apiSuccess([
        'url' => URL::temporarySignedRoute(
            'api.qualifications.boletin.file',
            now()->addMinutes(10),
            ['studentId' => $studentId, 'classroomId' => $classroomId],
        ),
    ]);
}

public function boletinFile(Request $request, string $studentId, string $classroomId)
{
    $student = \App\Models\StudentData::findOrFail($studentId);
    $classroom = \App\Models\Classrooms::withoutGlobalScope('isNotArchivated')->find($classroomId);
    // sin user autenticado → observaciones solo públicas (default seguro)
    return $this->boletinPdf($student, $classroom, null, $request->input('period'));
}
```
